# 基于 MyBatis-Plus 的驾校学员档案管理系统的设计与实现

项目主题：驾校学员档案管理系统（计算机毕业设计演示）。

## 技术栈

- 当前演示：Vue 3、Python、SQLite。
- 选题方案：Vue 3、Spring Boot、SQLite（部分技术尚未接入）。

## 项目功能

支持学员档案查询、筛选、维护和 CSV 导出，并记录操作日志。

完整方案规划包括：学员报名、档案管理、学时记录、约考排期、教练管理、车辆管理、费用结算、通过率分析。部分功能尚待开发。

## 运行方式

在项目目录运行 `python3 backend/server.py`，然后访问 http://127.0.0.1:8000。
